A recorded Claude Code session

We'll show how the Opus 5.5 model and Claude harness work together to add a simple feature to an existing codebase. The codebase we use is Recipe Manager, a small Flask web app for saving recipes. It extracts recipes from web pages and images and stores them in SQLite, alongside lighter “recipe ideas”. It comes with a suite of 226 pytest tests and an AGENTS.md file of instructions for coding agents. The feature we asked Claude to build is a filter on the recipe collection: All, Full recipes or Recipe ideas. It has to work together with the existing title and tag search, keep the search text when the filter changes, update the displayed count, and show helpful feedback when nothing matches. Claude also had to add tests and run the project's checks.

A coding agent is two programs taking turns. The left column is everything the harness (here, Claude Code) does: it builds the transcript, checks each request against its permissions, runs tools in the workspace and decides when to stop. The right column is everything the model does: it reads the transcript and writes thinking, text and tool requests. Arrows mark the moments when something passes between the two.
