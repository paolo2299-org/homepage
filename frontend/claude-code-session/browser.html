A recorded Claude Code session

Coding: add a feature to an app Browser: shop on Amazon

We'll show how the Sonnet 5.5 model and Claude harness work together to complete a task in a web browser. Through the Claude in Chrome extension, Claude sees a page as screenshots and acts on it by clicking, typing and scrolling. The task we gave it was a small shopping errand on Amazon UK: find a 26–28 cm induction-compatible frying pan for under £25, compare at most two candidates, add one to an empty basket, and stop before checkout.

The prompt


  







  

    
A browser agent is two programs taking turns. The left column is everything the harness (here, Claude Code with the Claude in Chrome extension) does: it builds the transcript, checks each request against its permissions, runs tools in the browser and decides when to stop. The right column is everything the model does: it reads the transcript, including screenshots of the page, and writes thinking, text and tool requests. Arrows mark the moments when something passes between the two.
